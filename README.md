# SyntaxLab

SyntaxLab draws the grammatical structure of a sentence and explains every label in it: a
**phrase-structure (constituency) tree**, a **dependency graph**, and a word-by-word
interlinear analysis of parts of speech and morphology. It is built for students and teachers
of English and linguistics.

Every analysis comes from an identified, evaluated parser. Nothing is generated by a chatbot,
and nothing is hand-drawn for particular sentences. When a model can't do something, the
interface says so instead of substituting something else.

> **Status:** English analysis and visualization are implemented and tested. Filipino
> (Tagalog), comparison, learning exercises and the parsing-algorithm lab are researched or
> planned. See [Roadmap](docs/roadmap.md) and [Progress](docs/progress.md).

## Features (implemented)

- **Analyzer.** Enter a sentence, pick a language and the analyses to show.
- **Phrase-structure tree.** Textbook layout with words on one baseline. Phrases can be
  collapsed into the triangle notation. Zoom, pan, fit and reset. Keyboard navigation follows
  the branches.
- **Dependency graph.** Labelled arcs nested by span, root marker, selectable words and
  relations, relation labels that can be hidden.
- **Interlinear strip.** Word, lemma, part of speech, Leipzig-style feature glosses and
  relation, aligned in columns. It doubles as the accessible table view.
- **Explanations.** Curated definitions for every UD relation, UPOS tag, UD feature and Penn
  Treebank label. Each is marked *Curated definition* or *Parser output*.
- **Provenance.** Engine, model files, annotation scheme per layer, and processing time are
  shown for every analysis. No invented confidence scores.
- **Export.** SVG (with embedded fonts) and PNG of the whole diagram as displayed.
- **Pluggable languages.** Languages are YAML configuration; engines are plug-ins. See
  [Adding a language](docs/adding-a-language.md).

## Language capability matrix

| Capability | English | Filipino (Tagalog) |
|---|---|---|
| Tokenization, POS, lemma, morphology | ✅ Stanza 1.15 | 🔬 researched, not enabled |
| Dependency (Universal Dependencies v2) | ✅ LAS 89.7 on UD EWT test¹ | 🔬 calamanCy v0.2.0 evaluated, LAS 76.5–77.1 |
| Constituency (Penn Treebank) | ✅ F1 ≈ 93 (published) | ❌ no parser or treebank exists |
| Alternative analyses | ❌ parsers return one analysis | ❌ |

¹ Measured by us; conditions in [nlp-model-evaluation.md](docs/research/nlp-model-evaluation.md).
On a gold regression set of 74 categorized EWT sentences: UPOS 97.6, UAS 95.5, LAS 94.1.

## Architecture

```
Next.js 16 app (React 19, TypeScript, Tailwind 4, shadcn/ui, D3 zoom)
        │  typed client generated from the OpenAPI schema
        ▼
FastAPI parser API (Python 3.12)
   language registry ── config/languages.yaml
   engines (plug-ins) ── stanza (built in) │ any package via entry points
   validation of every parse (trees, spans, arcs) · glossaries per annotation scheme
   per-language worker thread · bounded queue · timeout · LRU cache · rate limit
```

Details: [docs/architecture.md](docs/architecture.md) · API: [docs/api.md](docs/api.md)

## Quick start

Requirements: Node ≥ 20.9 with pnpm 10, and [uv](https://docs.astral.sh/uv/) (installs
Python 3.12 for you).

```bash
pnpm install
cd services/parser-api && uv sync --extra stanza && uv run syntaxlab-api download-models && cd ../..
pnpm dev:api     # parser API on http://127.0.0.1:8710 (models load in ~10–80 s)
pnpm dev:web     # web app on http://localhost:3000
```

More: [docs/development.md](docs/development.md)

## Testing

```bash
pnpm test                                          # web unit tests + API unit/HTTP tests

cd services/parser-api && uv run pytest -m models  # linguistic regression on real models
```

What is covered, and how: [docs/testing.md](docs/testing.md)

## Known limitations

- Parsers return a single analysis and can be wrong, especially on ambiguous or unusual
  sentences.
- The dependency and constituency views come from **two independent models** and can disagree
  (e.g. PP attachment).
- Penn Treebank labels (`NN`, `VBD`, `SBAR`) differ from introductory textbook categories.
  Explanations give the closest textbook category as a reading aid only.
- Parsing runs on CPU: expect about 1–5 s per sentence.

Full list: [docs/linguistic-limitations.md](docs/linguistic-limitations.md)
