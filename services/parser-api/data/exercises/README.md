# Learning exercises

## Part-of-speech and dependency exercises (`ud-en-*.yaml`)

Generated by `scripts/build_learning_exercises.py` from the **UD English Web Treebank
(UD_English-EWT)**, release r2.18, dev split. Each answer key is the treebank's manual (gold)
annotation, copied unchanged; sentences are selected by the deterministic rules in the script.

- Source: https://github.com/UniversalDependencies/UD_English-EWT (tag `r2.18`)
- License: **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**,
  https://creativecommons.org/licenses/by-sa/4.0/
- Citation: Silveira, N., Dozat, T., de Marneffe, M.-C., Bowman, S., Connor, M., Bauer, J.,
  & Manning, C. D. (2014). A Gold Standard Dependency Corpus for English. *LREC 2014*.

These files are distributed under CC BY-SA 4.0, separately from SyntaxLab's MIT-licensed code.

## Tree-building exercises (`grammar-*.yaml`)

Written for SyntaxLab (MIT). They name a preset grammar and a sentence only; the answer key is
computed when an answer is checked: **every** parse the Earley parser finds for the sentence
under that grammar is accepted.
